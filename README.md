# New York Times Top 100 Restaurants Analyzer

A Java and Processing application that parses annual New York Times NYC restaurant datasets from 2024 and 2025 to analyze trends and identify the most recurring cuisines.

## Features

* **Multi-Year Data Parsing:** Processes restaurant rankings and details line-by-line from `restaurants2024.txt` and `restaurants2025.txt`.
* **Object-Oriented Structure:** Organizes dataset entries through custom data models (`Restaurants.java`).
* **Cuisine Trend Analysis:** Tracks frequency and identifies recurring culinary categories across consecutive annual rankings.

## How to Run

1. Clone or download this repository.
2. Ensure `restaurants2024.txt` and `restaurants2025.txt` are in the root directory.
3. Open the project in your Java IDE (IntelliJ IDEA, Eclipse, or VS Code).
4. Ensure the **Processing core library** (`core.jar`) is added to your project dependencies/classpath.
5. Run `Main.java`.

## Requirements

* Java JDK 8 or higher
* Processing 3/4 `core.jar` library
